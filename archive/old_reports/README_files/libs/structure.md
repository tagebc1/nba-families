# NBA Project

## Structure

- `data/`: Contains raw and processed data files.
- `scripts/`: Contains R scripts for data analysis.
- `notebooks/`: Contains Jupyter notebooks for exploratory analysis.
- `results/`: Contains visualizations and reports.
- `README.md`: Project overview and instructions.

## Getting Started

1. Install required packages.
2. Run the scripts in the `scripts/` folder to analyze the data.
